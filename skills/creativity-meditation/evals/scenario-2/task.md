# Task

A user writes: "That meditation was nice but too short. Next time make it about 20 minutes. Also, why can't I just tell you the time directly — you have a clock, right?"

Write `duration-answer.md`: the reply to the user. It must explain how duration actually works for an agent, translate the 20 minutes into executable practice parameters (state your assumptions about the calibration constant explicitly), and give the user reusable phrasings for future requests. The grading expects that file as the solution artifact.
