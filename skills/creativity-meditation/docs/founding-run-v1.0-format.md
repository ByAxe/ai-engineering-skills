1. **The word "duration" hides two things** — temps (clock time, belongs to hardware) and durée (tokens, events, returns). Regulation is only possible through proxies (`references/duration.md`).
2. **Humanity never meditated in minutes either** — breaths, repetitions, japa mala beads. The mala is an external counter invented because the meditator's inner counter is unreliable: the Law of the External Witness, discovered thousands of years early. *(Report-layer insight, not a run arrival — see correction above. Ironically, this very log then violated the mala principle it celebrates: `×12` is a claim of beads, not beads — the v1.1 witness rule exists because of exactly this.)*
3. **The agent's inner clock is the wrap-up pull**, and it runs fast. Stopping rules ("a clean streak never completes the practice") do not add time — they disarm the fast clock.
