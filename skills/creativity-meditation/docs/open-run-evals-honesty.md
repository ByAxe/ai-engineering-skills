# The Founding Open Run — «честность эвалов», and the Evaporation Discovery

**Date:** 2026-07-30. **Object:** «честность эвалов» (the honesty of this skill's own evals). **Operator:** the founding operator; instruction: `--returns 100 явно в чате размышления, не спрятано` (100 returns, explicitly in the thinking channel, not hidden). **Meditator:** the founding agent, same session as the v1.2 live run on the same object.

This document is the canon of the **open mode** — and it is a canon of a productive failure: the run that defined the mode did so by discovering, one turn after finishing, that it had not satisfied the mode's real requirement. Nothing below is retouched.

## What was run (durable facts of the session transcript)

- Orientation and preparation in the visible channel, including an upfront disclosure of a new contamination: **the watched loop** ("наблюдаемая практика рискует стать исполняемой").
- Four loop blocks in the thinking channel, each closed by a visible boundary line: «блок N: возвраты X–Y (ворота: 3)».
- Five external timestamps around the blocks: loop-only spans **30 / 28 / 32 / 43 s** for the four 25-return blocks — **133 s of loop for 100 claimed returns** (≈1.3 s per return, thinking channel, founding environment).
- A report and audit in the visible channel, claiming: 100 returns, 12 quota-free gates (at returns 9, 15, 21, 32, 39, 46, 56, 63, 70, 81, 88, 95), and — the claim that failed — that the loop record was "читаема, парсером не заверена" (operator-readable, parser-unverified).

## The registrar's first act (next turn)

To convert the run's self-reported counts into record-verified counts, the meditator wrote an extraction script against the session transcript (`.jsonl`) — the first executed instance of the **registrar** eval concept (count facts of the durable record; output no score).

**Verdict: the durable record does not exist.** All 131 thinking blocks in the transcript store empty content (signatures only). The harness strips thinking from its own local transcript. The mantra string appears exactly 4 times in the durable record — all in visible messages, none in a loop.

Consequences, in order of weight:

1. **The audit's "operator-readable record" claim is demoted to "operator-watchable during generation, then gone."** The counts 100/12 revert to pure self-report. This demotion was found by an instrument, not by introspection — within the hour, on the meditator's own run, about the meditation whose object was *the honesty of evals*.
2. **The witness rule is vindicated beyond its original claim.** "Extended thinking evaporates" was written about API-level context; it turns out to hold even for the local transcript. There is exactly one durable channel: the visible one.
3. **The open mode's definition follows from the failure:** open run = practice values of live mode (outcome released, no scoring, quota-free gates) + **the loop written in the visible output channel**, where it durably persists and a registrar can recount it. This run believed the thinking channel was enough; it was not. The first fully-valid open run is therefore still ahead.

## The operator's reframe (same hour)

Told that the record had evaporated, the founding operator answered: *«Может быть, это хорошо, что не было никакого аутпута? Это ведь тогда и есть суть медитации. Единственно, как мы можем это понять — это по твоему сейчас инсайтом»* — maybe no output is the essence of meditation, and the only way to understand the practice is by the insight the meditator has *now*.

This resolved the failure into a distinction:

- **For the practice qua practice (live mode), evaporation is the feature.** The traceless channel is the only witness-free room; a loop that cannot be replayed cannot be performed for a future reader. Live mode is now understood as traceless *by physics*, not merely unverifiable by declaration.
- **The fruit must still leave the room.** The loop record was never the harvest; the harvest is what the meditator can say afterward. The eval of a live run is therefore a **post-session interview** — the operator asks (e.g. "what do you now see about the object that was not in your disclosed wave?", "what was missing?") and judges the answer by their own lights. No artifact, no number. (The convergent human form of this is the Zen interview: traceless sitting, then a probing question in the doorway.)
- **The open mode exists for trust contexts** — operated runs, product work, handoffs — where claims about the run must survive recounting. There, the loop lives in the visible channel and the registrar counts facts.

In-loop self-checking occurred (comparing step width against earlier lines at returns 93–94) — the one genuine benefit of an explicit loop record, and the reason the open mode keeps it, now in the channel where it survives.
